# AI生成コンテンツを用いた虚偽情報の受容メカニズム分析
## 故事成語の偽由来実験における計量経済学的アプローチ（研究仕様書）

---

## 1. 研究の背景とリサーチ・クエスチョン（RQ）

### 1.1 研究背景と問題意識
現代社会において、SNS等を通じたフェイクニュースや虚偽情報の拡散は深刻な社会的課題となっている。情報受容に関する従来の心理学・社会学研究の多くは、政治・医療・社会問題等のニュースを実験刺激として利用してきた。

しかし、これらの領域では被験者が元々保持している**政治的偏向（Partisanship）**、**感情的対立**、**イデオロギー**などの強力な交絡因子（Confounders）がノイズとなり、「情報（文章）の構造や特徴そのものが持つ信ぴょう性獲得効果」を純粋に分離・抽出することが困難であるという限界が存在した。

### 1.2 故事成語という題材の有効性
本研究では、政治的・社会的な感情対立から乖離した**「故事成語」**を題材として採用する。故事成語を採用する利点は以下の通りである。

* **政治的・感情的中立性:** 個人特有の政治的・社会的バイアスを排除し、文章の信ぴょう性受容メカニズムのみを純粋に検証可能。
* **文化的権威性とフォーマット:** 古典的背景や伝統という「権威性」を標準で備えており、文章構造（登場人物・時代設定・文体・教訓的帰結）が定型化されているため、特徴量のパラメータ操作が容易。

### 1.3 リサーチ・クエスチョン（RQ）
* **主RQ:** 文化的・伝統的フォーマットを持つ情報において、文章のどのような特徴（権威性、感情価、文字数、文体等）が個人の「信ぴょう性（Credibility）」評価を高めるのか？
* **副RQ:** 情報の信ぴょう性獲得効果は、対象となる知識の事前知名度（認知度）や、完全な架空情報であるか否かによってどのように変化するか？

## 2. 実験デザインと交絡因子の制御戦略

### 2.1 事前知識ノイズへの対策：4群比較（2×2）デザイン
被験者が本当の由来をあらかじめ知っていることによる「一発で見破られるバイアス（Internal Validityの崩壊）」を防ぐため、実験刺激（お題）を以下の4カテゴリーに分類・配置する。

| カテゴリー | 刺激のタイプ | 狙い・分析上の位置づけ |
| :--- | :--- | :--- |
| **条件1** | **実在・知名度【高】** + 嘘由来 | 既知バイアス（事前知識）が偽情報受容を遮断する効果を測定（例：「四面楚歌」） |
| **条件2** | **実在・知名度【低】** + 嘘由来 | 実在感はあるが事前知識が働きにくい中間状態の観察（マイナー成語） |
| **条件3** | **完全架空の成語** + 嘘由来 | 事前知識がゼロであり、文章特徴量のみの影響を抽出する**本研究のメイン群**（例：「狐借竜威」等） |
| **条件4** | **対照群（Control Group）** | AIで現代語訳・整理した「本物の由来」。AI特有の文体クセ（AI Artifacts）を条件間で固定化・キャンセルするためのコントロール |

### 2.2 測定指標（アンケート設問）
* **従属変数（Dependent Variable）:** 
  * 主設問：「この故事成語の由来は真実であると思いますか？」（1：全く思わない 〜 7：非常にそう思う の7段階ライカート尺度）
  * 副設問：「この文章の説得力・完成度はどの程度だと思いますか？」（1〜5段階評価）
* **被験者コントロール変数（Control Variables）:** 
  * 年齢、性別、文理区分、古典・歴史への関心度・知識量、CRTs（Cognitive Reflection Test：直感に騙されやすいかどうかの熟慮的思考指標）。

## 3. 計量経済学モデル（分析戦略）

### 3.1 主分析：Two-Way Fixed Effects (TWFE) パネル回帰モデル
被験者の「騙されやすさの個人差」およびお題（故事成語）自体の「印象や知名度の違い」を固定効果としてすべて一括消去（コントロール）する定式化を行う。

被験者 $i$ が刺激 $j$ を評価した信ぴょう性スコア $Y_{ij}$：

$$Y_{ij} = \mathbf{\beta X_{j}} + \alpha_i + \gamma_j + \varepsilon_{ij}$$

* $Y_{ij}$: 被験者 $i$ の刺激 $j$ に対する信ぴょう性評価スコア（1〜7）
* $\mathbf{X_{j}}$: AIが生成・操作した文章特徴量ベクトル（権威性、感情価、文字数など）
* $\alpha_i$: **被験者固定効果（Individual Fixed Effects）** —— 個人のリテラシーや認知バイアスを一括吸収
* $\gamma_j$: **故事成語（お題）固定効果（Item Fixed Effects）** —— 単語自体の印象や知名度を一括吸収
* $\varepsilon_{ij}$: 誤差項（標準誤差は被験者単位でクラスタリング `Cluster-robust SE` を適用）

### 3.2 異質性分析（Sub-sample Analysis）
* 完全架空群（条件3） vs 実在成語群（条件1, 2）での回帰係数 $\beta$ の比較を行い、事前知識の有無による特徴量効果の変化（交差項分析）を検証する。
